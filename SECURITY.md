# Security Policy

## Supported Versions

This is an active research repository. Security fixes and public-safety
corrections apply to the current `main` branch.

## Reporting a Security Issue

Please do not open a public issue for reports involving:

- accidentally committed credentials, tokens, private keys, or private contact
  details
- unpublished or restricted cultural, museum, archive, or source material
- copyrighted scans, images, bulk transcriptions, or long excerpts that should
  not be redistributed
- instructions or files that could expose private accounts or infrastructure

Report privately to the repository owner or maintainer. Include the affected
file path, commit or branch if known, and the minimum detail needed to reproduce
or verify the issue.

## Research Content Issues

Scholarly disagreements, source-quality concerns, and decipherment objections
are normally contribution or review issues, not security issues. Use private
reporting only when the concern involves sensitive, restricted, private, or
potentially infringing material.

## Response Expectations

The maintainer will triage reports as soon as practical, remove or redact unsafe
material when appropriate, and document public-facing corrections without
disclosing sensitive details.
